What the record does not say
All HTTP results are from one audit day, 7 September 2026. HTTP responses and surname matches do not establish that campaign content survived.

The server is read-only. There is no write path, no key, and no second answer for anyone who asks politely — a party cannot get a softer reply than the public one.
