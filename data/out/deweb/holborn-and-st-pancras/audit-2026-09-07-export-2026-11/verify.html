Verify this Civicord bundle

Bundle version: audit-2026-09-07-export-2026-11

This directory is a static evidence bundle. Its files are useful only if the bytes match the hashes in manifest.json and, after publication, the SHA-256 values recorded by the X Layer SiteRegistry.

Local verification

python scripts/tapeout/evidence_bundle.py verify /path/to/bundle --self-test

Chain verification after publication

Run the read-only direct-chain verifier with the published container address:

python scripts/tapeout/verify_deweb.py /path/to/bundle \
  --container <container> \
  --prefix civicord/uk-2024-25/holborn-and-st-pancras/audit-2026-09-07-export-2026-11

It pins one block, requires agreement between independent RPC operators, checks the pinned SiteRegistry implementation, reads every file, and verifies byte length plus SHA-256. It fails closed on disagreement. A manual spot check can compare one file with:

cast call <SiteRegistry> 'fileInfo(address,string)(uint32,string,bytes32,uint40,uint256)' <container> <path> --rpc-url https://rpc.xlayer.tech
